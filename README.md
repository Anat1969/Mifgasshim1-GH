# בינה מלאכותית לאדריכלים

אפליקציה סטטית בעברית לקורס בשני מפגשים. שלושה דפים: כללי, מפגש א (מבחן התב"ע, עם מודל מגרש בתלת-ממד) ומפגש ב (ניהול הסטודיו).

- כתובת חיה: https://mifgasshim1-gh.vercel.app
- קוד: https://github.com/Anat1969/Mifgasshim1-GH

## הרצה מקומית

אין התקנה ואין build. מריצים שרת סטטי בתיקיית הריפו:

```
npx serve .
```

## עריכת תוכן

- הדף הכללי ומפגש א: `index.html`.
- מפגש ב, הפרומפטים ורשימת האפליקציות: הקבועים בראש `assets/app.js`.
