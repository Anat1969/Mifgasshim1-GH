# בינה מלאכותית לאדריכלים

אפליקציה סטטית בעברית לקורס. ארבעה דפים: כללי, מפגש ב (מבחן התב"ע, עם מודל מגרש בתלת-ממד), מפגש א (ניהול הסטודיו) ומפגש ג (מהחלופה הנבחרת למודל עבודה).

- כתובת חיה: https://mifgasshim1-gh.vercel.app
- קוד: https://github.com/Anat1969/Mifgasshim1-GH

## הרצה מקומית

אין התקנה ואין build. מריצים שרת סטטי בתיקיית הריפו:

```
npx serve .
```

## עריכת תוכן

- הדף הכללי ומפגש ב: `index.html`.
- מפגש א, הפרומפטים ורשימת האפליקציות: הקבועים בראש `assets/app.js`.
