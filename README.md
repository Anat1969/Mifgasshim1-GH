# בינה מלאכותית לאדריכלים: מפגשים 1 ו-2 וחומר עזר

אתר סטטי בעברית. ארבעה דפים: בית, מפגש 1, מפגש 2, וחומר עזר.

## הרצה מקומית

אין התקנה ואין build. פותחים את `index.html` בדפדפן, או מריצים שרת סטטי:

```
npx serve .
```

## עריכת תוכן

כל הטקסט נמצא ב-`assets/content.js`. מעדכנים שם, והדפים מתעדכנים.

## פריסה

פרויקט סטטי ב-Vercel, בלי build command ובלי output directory. תיקיית השורש היא תיקיית הריפו.

## מסמך מפרט

ראו `CLAUDE.md`.
